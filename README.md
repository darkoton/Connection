## 📖 Description

React Messenger is a modern messaging application inspired by Telegram. The project allows users to communicate in real time, add friends, exchange media, and manage conversations through a fast and intuitive interface. Firebase is used as the backend to provide authentication, real-time database synchronization, and cloud storage.

---

## ✨ Key Features

- User registration and authentication.
- Real-time messaging.
- Friend search and friend requests.
- Personal contact list.
- Image sharing in chats.
- Emoji picker integration.
- Image preview gallery.
- Copy messages to clipboard.
- Responsive interface.
- Modern Material Design UI.

---

## 🛠 Development

- Built with React 18.
- Vite development environment.
- React Router for client-side routing.
- Firebase Authentication.
- Cloud Firestore real-time database.
- Firebase Storage for media files.
- Zustand for global state management.
- Material UI component library.
- Tailwind CSS utility framework.
- Axios for HTTP requests.
- Emoji Picker integration.
- React Photo View for image previews.
- Component-based architecture.
- Clean and scalable project structure.

---

## 🎯 Result

The project demonstrates the development of a modern real-time messaging platform with authentication, friend management, media sharing, and cloud-based data synchronization. It showcases modern React architecture, Firebase integration, responsive design, and reusable component development.
